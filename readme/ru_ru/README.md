# AstralRinth

AstralRinth — лаунчер Minecraft с собственной визуальной идентичностью, созданный для чистого и гибкого игрового опыта. Он предлагает неоновый интерфейс, отсутствие рекламы и промо-блоков, гибкую работу с аккаунтами и обновления через сервисы Xorison.

## Скачивание и установка

1. Откройте [страницу релизов AstralRinth](https://xorison.dev/product/astralrinth/).
2. Скачайте пакет для своей операционной системы.
3. Запустите установщик или откройте загруженный пакет.

| Тип файла | Операционная система | Примечание |
| --- | --- | --- |
| `.msi, .exe` | Windows 10/11 | Запустите установщик и следуйте его указаниям. |
| `.dmg, .app` | macOS | Откройте образ и перенесите AstralRinth в «Программы». |
| `.deb, .rpm, .AppImage` | Linux | Установите пакет через менеджер пакетов своего дистрибутива. |

Не используйте релизы, версия которых начинается с `dev`, `nightly` или `dirty`: они предназначены для тестирования и могут быть нестабильными.

## Возможности AstralRinth

- Полностью собственная идентичность AstralRinth: название, иконки, splash-screen, заголовки окон и неоновый стиль интерфейса.
- Сосредоточенный игровой опыт без рекламы, промо-материалов, опросов, Pride-медиа и недоступных в России компонентов Modrinth.
- Русский и английский интерфейс собственных экранов и сообщений AstralRinth.
- Поддержка аккаунтов:
  - Microsoft;
  - Ely.by, включая управление скинами через Ely.by;
  - внешних Minecraft-аккаунтов через OAuth Device Authorization;
  - офлайн-аккаунтов для локальной игры и тестирования.
- Управление скинами доступно только для типов аккаунтов, которые его поддерживают.
- Управление библиотеками `authlib-injector`: просмотр локальных версий, установка, выбор версии или автоматическая установка подходящей актуальной версии при необходимости.
- Надёжный запуск офлайн-аккаунтов, в том числе на Minecraft 1.16.4 и 1.16.5, а также понятное восстановление после ошибок валидации аккаунта.
- Отдельный раздел настроек AstralRinth.
- Обновления через сервисы Xorison: AstralRinth проверяет релизы, выбирает подходящий установщик для Windows, macOS или Linux, скачивает и запускает его. На странице диагностики обновлений можно посмотреть состояние и подробности обновления.
- Discord Rich Presence с фразами AstralRinth и ссылкой на скачивание лаунчера.

## Быстрый старт

1. Скачайте и установите последнюю стабильную версию.
2. В разделе **«Аккаунты»** войдите через Microsoft или Ely.by, завершите вход по коду устройства для поддерживаемого внешнего аккаунта либо создайте офлайн-аккаунт.
3. Создайте или выберите инстанс Minecraft.
4. Если внешний аккаунт использует сервер авторизации, откройте настройки инстанса и настройте `authlib-injector`.
5. Запустите игру. AstralRinth по возможности использует рекомендованную версию Java; при необходимости её можно выбрать вручную в настройках.

## Обновления и поддержка

AstralRinth сообщит, когда доступно обновление. Подтвердите установку в окне обновления — лаунчер использует пакет для вашей системы. Если обновление не завершилось, перед обращением в поддержку откройте диагностику обновлений в настройках AstralRinth.

Поддержка: [Telegram-канал AstralRinth](https://xorison.dev/product/astralrinth/support)

## Важно

AstralRinth — независимый проект на основе Modrinth. Соблюдайте правила Minecraft и условия используемых сервисов авторизации. Мы рекомендуем использовать лицензионную версию Minecraft.
