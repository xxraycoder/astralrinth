# AstralRinth

AstralRinth — лаунчер Minecraft с собственной визуальной идентичностью, созданный для чистого и гибкого игрового опыта. Он предлагает интерфейс в стиле Modrinth с опциональными эффектами Liquid Glass, отсутствие рекламных размещений в лаунчере, гибкую работу с аккаунтами и обновления через сервисы Xorison.

## Скачивание и установка

1. Откройте [страницу релизов AstralRinth](https://xorison.dev/product/astralrinth/).
2. Скачайте пакет для своей операционной системы.
3. Запустите установщик или откройте загруженный пакет.

| Тип файла | Операционная система | Примечание |
| --- | --- | --- |
| `.msi, .exe` | Windows 10/11 | Запустите установщик и следуйте его указаниям. |
| `.dmg, .app` | macOS | Откройте образ и перенесите AstralRinth в «Программы». |
| `.deb, .rpm` | Linux | Установите пакет через менеджер пакетов своего дистрибутива. |
| `.AppImage` | Linux | Разрешите выполнение файла и запустите его напрямую. |

Для обычного использования избегайте тестовых релизов и пакетов, имена которых начинаются с `dev`, `nightly`. Сборочный workflow помечает экспериментальные пакеты для отдельных платформ префиксом `nightly_expiremental_` в имени файла.

## Возможности AstralRinth

- Собственный брендинг AstralRinth: иконки, заставка, заголовки окон и интерфейс в стиле Modrinth.
- Опциональные эффекты Liquid Glass с уровнями «Матовый», «Стандартный» и «Прозрачный». Эффекты настраиваются в отдельном разделе визуальных настроек AstralRinth без изменения выбранной цветовой темы.
- Рекламные размещения и интерфейс согласия на рекламу удалены; аналитика использования принудительно отключается при запуске. В production-сборках остаются отправка ошибок и трассировка через Sentry, а в Windows — предложения пройти опрос.
- Русский и английский переводы экранов и сообщений, добавленных AstralRinth.
- Вход в Minecraft через Microsoft, Ely.by или офлайн-аккаунт. Для Ely.by используется авторизация OAuth по коду устройства.
- Управление скинами с учётом типа аккаунта: редактирование скинов Mojang доступно для Microsoft-аккаунтов; для неподдерживаемых типов аккаунтов лаунчер предлагает перейти к провайдеру, если такая ссылка доступна.
- Управление `authlib-injector` для внешней авторизации: просмотр локальных JAR-файлов, установка и выбор версии или автоматическая установка совместимой версии при необходимости.
- Поддержка офлайн-аккаунтов, включая обход проблемы совместимости в Minecraft 1.16.4 и 1.16.5.
- Отдельный раздел настроек AstralRinth и одноразовое уведомление с предложением добавить случайные пользовательские иконки инстансам без иконок.
- Обновления лаунчера через Xorison: проверка релизов, выбор установщика для Windows, macOS или Linux и диагностика обновлений в настройках, включая операционную систему и архитектуру.
- Discord Rich Presence со статусами AstralRinth и ссылкой на скачивание лаунчера.

## Быстрый старт

1. Скачайте и установите последнюю стабильную версию.
2. В разделе **«Аккаунты»** войдите через Microsoft или Ely.by, завершите вход по коду устройства для поддерживаемого внешнего аккаунта либо создайте офлайн-аккаунт.
3. Создайте или выберите инстанс Minecraft.
4. Для Ely.by AstralRinth пытается автоматически установить совместимую библиотеку `authlib-injector`, если ни одна ещё не установлена. Для ручной установки или выбора версии откройте **Настройки → AstralRinth → Библиотеки аутентификации**.
5. Запустите игру. AstralRinth по возможности использует рекомендованную версию Java; при необходимости её можно выбрать вручную в настройках.

## Визуальные настройки

Откройте **Настройки → AstralRinth → Визуальные настройки**, включите или отключите **Liquid Glass**, выберите **Уровень стекла** и сохраните изменения:

- **Матовый:** почти непрозрачные поверхности с усиленным размытием, без декоративных градиентов.
- **Стандартный** (по умолчанию): полупрозрачные поверхности с размытием и многослойными градиентами.
- **Прозрачный:** более прозрачные поверхности без фонового размытия стекла и декоративных градиентов.

Ползунок уровня недоступен, когда Liquid Glass отключён. Изменения применяются после сохранения; сброс несохранённых изменений возвращает сохранённые значения. Включение эффекта сохраняется в существующей настройке лаунчера, а уровень — локально для этой установки приложения, без синхронизации с аккаунтом. Если локальное хранилище недоступно, после перезапуска уровень может вернуться к стандартному.

Эта настройка отмечена как бета и не меняет цветовую тему, выбранную в настройках внешнего вида. Настройки доступности или отсутствие поддержки размытия могут включать непрозрачные резервные поверхности. Отключите Liquid Glass, если эффекты снижают производительность или читаемость интерфейса.

## Обновления и поддержка

При запуске AstralRinth проверяет обновления через Xorison и сообщает, если сервис предлагает более новую версию. В окне обновления выберите пакет из доступных для вашей операционной системы и архитектуры. Перед продолжением создайте резервную копию данных лаунчера. Пакет загружается в папку загрузок: в Windows запускается установщик, в macOS открывается пакет, а в Linux — содержащая его папка для ручной установки. Завершить установку может потребоваться вне лаунчера.

Если обновление не завершилось, проверьте папку загрузок и журналы лаунчера, затем перед обращением в поддержку откройте диагностику обновлений в настройках AstralRinth. Она показывает состояние релиза и API, а не подтверждение успешной установки.

Поддержка: [Telegram-канал AstralRinth](https://xorison.dev/product/astralrinth/support)

AstralRinth — независимый проект на основе Modrinth. Соблюдайте правила Minecraft и условия используемых сервисов авторизации. Мы рекомендуем использовать лицензионную версию Minecraft.
